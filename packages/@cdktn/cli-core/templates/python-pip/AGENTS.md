# AGENTS.md

This is a [CDK Terrain](https://cdktn.io) (CDKTN) project written in Python. CDKTN is the
community-maintained successor to CDK for Terraform (CDKTF): the library and CLI are both named `cdktn`.
Packages, imports and some behavior differ from CDKTF, so check the CDKTN docs instead of relying on
prior CDKTF knowledge.

## Docs

- Docs MCP server: https://cdktn.io/docs/mcp (streamable HTTP, no auth). `.mcp.json` registers it for
  Claude Code; for other clients add it as a remote MCP server, or run
  `claude mcp add --transport http cdktn https://cdktn.io/docs/mcp`
- Agent skill: https://cdktn.io/docs/skill.md
- LLM index: https://cdktn.io/llms.txt
- Migrating from CDKTF: https://cdktn.io/docs/release/upgrade-guide-v0-22

## Layout

- `main.py`: the app; define stacks and resources here
- `cdktf.json`: project config (language, app command, providers, modules)
- `imports/`: provider and module bindings generated by `cdktn get`; do not edit by hand
- `cdktf.out/`: Terraform JSON written by `cdktn synth`; do not edit

## Commands

- `cdktn provider add <provider>`: add a provider (uses a prebuilt package when one exists)
- `cdktn get`: generate bindings for the providers and modules in `cdktf.json`
- `cdktn synth`: synthesize Terraform JSON into `cdktf.out/`
- `cdktn diff [stack]`: plan changes for a stack
- `cdktn deploy [stack]` / `cdktn destroy [stack]`: change real infrastructure; ask before running
- `pytest main-test.py`: run unit tests

The `help` file lists every command for this project.
